# 文序 · 公众号排版美化工具

文序（darmk Studio）是一款面向微信公众号写作者的 Markdown 排版工具。它将 Markdown 转换为带内联样式的富文本，支持主题切换、代码高亮、图片处理、移动端 / PC 端预览，并可直接复制到公众号编辑器。

> 让文字有序，让内容好看。

## 在线体验

## 主要功能

| 功能 | 说明 |
| --- | --- |
| Markdown 编辑与导入 | 支持直接粘贴，也支持 `.md`、`.markdown`、`.mdown`、`.txt` 和包含图片的 ZIP 文件。 |
| 公众号富文本复制 | 生成带内联样式的 HTML，点击“复制到公众号”后可直接粘贴。 |
| 32 套文章主题 | 包含 Apple、字节科技、简约、科技、编辑部、东方、生活方式等不同风格。 |
| 主题分类与搜索 | 支持按分类、关键词、收藏和最近使用筛选主题。 |
| 主题画廊 | 查看完整文章示例，比较标题、引用、列表、图片、表格和代码效果。 |
| 10 套代码主题 | 支持深色 / 浅色代码风格，并按 JavaScript、TypeScript、Python、Java、Go、Rust、CSS、JSON 等语言区分语法颜色。 |
| 手机 / PC 预览 | 手机预览宽度 375px；PC 预览宽度 760px，支持“适配宽度”和“100% 原始尺寸”。 |
| 图片关联与发布处理 | 可关联本地图片目录或 ZIP，也可填写远程图片地址或使用自有上传接口。 |
| 发布检查中心 | 复制前检查图片、表格、代码语言和链接，并给出兼容性风险提示。 |
| 文章大纲 | 自动识别 Markdown 标题，点击标题可定位原文和预览位置。 |
| 同步滚动 | 编辑区与预览区可以按文章章节同步滚动。 |
| 专注模式与快捷键 | 可隐藏左右面板，使用快捷键快速导入、复制、预览和切换主题。 |

## 推荐使用流程

### 1. 导入 Markdown

打开在线地址，或在本地启动项目后访问 `/md2articlehtml/`。

可以采用以下方式导入文章：

- 直接把 Markdown 粘贴到左侧编辑区。
- 点击顶部“导入 Markdown”，选择 `.md`、`.markdown`、`.mdown` 或 `.txt` 文件。
- 导入包含相对路径图片的 ZIP 文件。ZIP 中可以同时包含 Markdown 文件和图片目录。
- 将 Markdown 文件拖到编辑区。

导入后，左侧是 Markdown 原文，中间是公众号预览，右侧是样式设置。

### 2. 处理文章中的本地图片

如果 Markdown 中包含这样的相对路径：

```markdown
![架构图](./assets/architecture.png)
```

点击顶部“图片”进入图片管理，可以选择：

1. **关联图片目录**：选择 Markdown 所在目录或图片所在目录，工具会按相对路径匹配本地文件。
2. **导入图片 ZIP**：适合文章和图片已经打包的情况。
3. **填写远程地址**：为单张图片填写可公开访问的 HTTPS 地址。
4. **使用自有上传接口**：配置自己的图床或图片上传服务后，可以批量上传。

图片尚未处理时不会阻止复制。复制结果会使用图片文字占位，粘贴到公众号后可以再补充图片。需要发布图片时，建议先完成关联或上传，并在发布检查中心确认图片状态。

### 3. 选择文章主题

右侧“样式工坊”中会显示当前主题。点击当前主题后，会从页面右侧打开主题选择面板，支持：

- 搜索主题名称、英文名、风格和用途。
- 按全部、精选、极简、科技、内容、东方、生活、品牌分类筛选。
- 查看我的收藏和最近使用。
- 点击主题后即时切换预览。
- 点击“浏览主题画廊”查看完整示例。

主题画廊适合详细比较不同主题；右侧主题面板适合日常快速切换。

### 4. 调整配色、正文和标题

主题确定后，可以在右侧继续调整：

- 主题配色。
- 正文字号。
- 正文行高。
- 标题样式。
- 代码主题和代码字号。
- 是否显示代码语言。
- 是否自动识别未声明语言的代码块。
- 是否换行显示超长代码。
- 是否显示图片说明。
- 是否启用脚注链接。

文章主题只影响排版样式，不会修改左侧 Markdown 原文。

### 5. 查看手机端和 PC 端效果

中间预览区可以切换：

- **手机**：按 375px 公众号阅读宽度预览。
- **PC**：按 760px 宽度预览。
- **适配宽度**：将 PC 预览缩放到当前可用空间，避免横向滚动。
- **100% 原始尺寸**：查看文章在 760px 原始宽度下的实际效果。

建议在复制前至少检查一次手机端，重点查看长标题、表格、代码块、列表和图片说明。

### 6. 使用大纲和同步滚动

左侧编辑区顶部点击“大纲”，可以查看文章标题结构：

- 点击大纲标题定位到 Markdown 原文。
- 点击预览中的标题也可以定位到左侧原文。
- 可以固定大纲，让大纲在定位后保持展开。
- 打开“同步滚动”后，编辑区和预览区会按文章章节保持同步位置。

### 7. 复制到公众号

点击顶部“复制到公众号”，工具会先打开发布检查中心，检查：

- 未处理的本地图片。
- 可能在手机端溢出的表格。
- 没有声明语言的代码块。
- 格式异常的链接。
- 当前文章的兼容性估算分数。

确认后点击“确认并复制”，再到公众号编辑器中粘贴。

复制注意事项：

- 每次修改主题或内容后，都要重新点击复制。
- 不要重复粘贴到已经出现错乱的旧内容结构中，建议先删除旧内容再粘贴。
- 图片、代码和表格粘贴后，建议在公众号手机预览中再检查一次。
- 兼容性评分是本工具的规则估算，不是微信公众号官方评分。

### 8. 导出 HTML

如果需要保存中间结果，可以使用顶部“导出 HTML”。导出的文件包含当前主题和内联样式，适合备份、二次检查或交给其他编辑工具处理。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl / ⌘ + K` | 打开主题选择 |
| `Ctrl / ⌘ + Shift + O` | 导入 Markdown / ZIP |
| `Ctrl / ⌘ + Shift + C` | 打开发布检查并确认复制 |
| `Ctrl / ⌘ + Shift + P` | 切换手机 / PC 预览 |
| `Ctrl / ⌘ + Shift + F` | 进入 / 退出专注模式 |
| `Ctrl / ⌘ + Shift + L` | 显示 / 隐藏编辑区 |
| `Ctrl / ⌘ + Shift + R` | 显示 / 隐藏样式面板 |
| `Ctrl / ⌘ + Shift + K` | 打开快捷键帮助 |
| `Esc` | 关闭主题选择、退出专注模式或关闭当前面板 |

普通的 `Ctrl / ⌘ + C` 仍然保留浏览器原生文本复制行为。

## 本地运行

环境要求：Node.js `>= 22.13.0`。

```bash
npm ci
npm run dev
```

开发服务启动后访问：

```text
http://localhost:3000/md2articlehtml/
```

Windows 下如果执行 `npm ci` 报 `EPERM`，先保存文章并停止本项目正在运行的开发服务，避免 `node_modules` 中的原生依赖被占用。

## 构建与静态预览

```bash
npm run build
npm start
```

构建成功后会生成：

```text
dist/client/index.html
dist/md2articlehtml.zip
```

ZIP 已包含 `md2articlehtml/` 顶层目录，可以直接解压到 Nginx 网站根目录。静态预览仍然访问：

```text
http://127.0.0.1:3000/md2articlehtml/
```

完整的 Nginx 子路径配置、CSP 要求、403 排查和目录结构见 [DEPLOY-NGINX.md](DEPLOY-NGINX.md)。

## Nginx 部署

项目适合部署在主域名的 `/md2articlehtml/` 子路径下。部署时需要注意：

1. 使用 `npm run build` 生成静态产物。
2. 将 `dist/md2articlehtml.zip` 上传到服务器。
3. 解压后确认首页位于 `/home/project/www/md2articlehtml/index.html`。
4. 将 [deploy/nginx-md2articlehtml.conf](deploy/nginx-md2articlehtml.conf) 中的 location 配置放入主域名的 `server {}`。
5. 执行 `nginx -t` 后 reload Nginx。
6. 确认线上 CSP 允许内联脚本、内联样式、HTTPS 图片和图床接口。

线上地址示例：

```text
https://www.darmk.com.cn/md2articlehtml/
```

## 数据与隐私

- Markdown 内容默认只在当前浏览器中处理，不会自动保存到服务器。
- 浏览器刷新前请先导出 HTML 或备份 Markdown 原文。
- 本地图片只有在你主动关联、填写远程地址或调用自有上传接口时才会处理。
- 不要在图片上传接口地址中填写 OSS、COS 等密钥，签名和鉴权应放在你自己的服务端。
- 公众号最终的 HTML 清洗、字体环境和图片可用性由微信公众号控制，工具无法完全保证所有设备表现一致。

```text
lib/         Markdown 转换、主题、代码高亮、图片和发布检查逻辑
public/      图标和公开静态资源
scripts/     静态构建、预览和成品检查脚本
tests/       功能回归测试

docs/        兼容性和品牌资源说明
```
